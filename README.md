# Climb4Dreams Landing Page

A responsive landing page built for Climb4Dreams.

## Live Demo

[View the live website] (https://climb4dreams-landing.vercel.app/) 

## Built With

* HTML
* CSS
* JavaScript

## About the Project

This project involved building a responsive landing page with a focus on layout, styling, user experience, and responsive design.

## Features

* Responsive layout
* Custom styling and animations
* Optimized images and assets
* SEO-friendly structure
* Deployed with Vercel

## Project Structure

```text
assets/       # Project assets
images/       # Images used throughout the site
index.html    # Main page
styles.css    # Styling
script.js     # JavaScript functionality
robots.txt    # Search engine crawling rules
sitemap.xml   # Site structure for search engines
```

## Deployment

The project is deployed on Vercel and has a live production version available above.
